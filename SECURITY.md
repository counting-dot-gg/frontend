# Security

Please don't report security problems in public issues, pull requests or
Discord channels.

Report them privately through GitHub instead:
[Report a vulnerability](https://github.com/counting-dot-gg/frontend/security/advisories/new).

Include what you found, how to reproduce it, and what an attacker could do
with it. You'll get a reply within a few days. Once we deploy a fix, we
publish the advisory and credit you, unless you'd rather we didn't.

Only the code in this repository is in scope. Don't test against
counting.gg itself: run the site locally (see `README.md`) and test there.
